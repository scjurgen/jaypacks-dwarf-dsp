The code of this repository is licensed under the MIT License (`LICENSE`). The MIT
License does not grant permission to use the brand identifiers below to identify or
promote a derivative product. The artwork has its own terms in `ARTWORK-LICENSE.txt`.

## Brand identifiers

- the project name `jaypacks-dwarf-dsp`
- `jaypack` (also `jaypacks`)
- `Krachpedal` and `Krachpedale` (the German plural)
- the logo, once the repository carries one (its path is added here)

No trademark licence is granted. Whether the names are registered as trademarks does not
change this notice; it only states what the author reserves.

## Allowed

- Factual references: "built from jaypacks-dwarf-dsp", "compatible with the plugins of
  jaypacks-dwarf-dsp", a link to the repository.
- Forking the code under MIT, under a different name and with different artwork.
- Building the plugins for your own use, see `ARTWORK-LICENSE.txt`.

## Not allowed without written permission

- Naming a fork, a product, a plugin pack or a band release after a brand identifier.
- Presenting a derivative product as made, endorsed or sold by the author.
- Using the logo or the pedal artwork to identify a derivative product.
